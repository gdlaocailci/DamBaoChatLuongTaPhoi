1. GitHub Pages (Miễn phí)

2. Máy chủ Web Độc lập

Đặt tệp index.html và ketnoi.js vào thư mục web của Nginx (/var/www/html) hoặc Apache, hoặc chạy nhanh bằng lệnh Python: python3 -m http.server 8080.

3. Google Apps Script Web App

Tạo Google Sheet -> Vào Tiện ích mở rộng > Apps Script -> Tạo cauhinh.gs, Code.gs và index.html (có thể chèn nội dung ketnoi.js) -> Nhấn Triển khai (Deploy) > Ứng dụng web mới.
